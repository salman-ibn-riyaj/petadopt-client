# 🎨 PetAdopt - Frontend Client

A highly responsive, fluid, and interactive user interface built with React, Next.js, and Tailwind CSS. This frontend provides an intuitive pet discovery experience, real-time feedback animations, and seamless integration with the secure PetAdopt authentication and server pipelines.

---

## 🚀 Purpose
The primary purpose of the **PetAdopt Client** is to provide animal lovers and pet owners with a fast, modern, and cross-device compatible interface to list animals for adoption, query listings dynamically, and safely request pet adoptions without complex paperwork.

---

## 🌐 Live URL
* **Frontend Application:** [https://petadopt-client-flame.vercel.app](https://petadopt-client-flame.vercel.app)

---

## ✨ Features (Frontend)
* **Intelligent Query & Categorization Engine:** Real-time search bar with case-insensitive text matching, categorical filtering by species, and dynamic pricing sorting (Low-to-High / High-to-Low).
* **HeroUI Premium Component Architecture:** Built using HeroUI's sleek, accessible, and highly customizable UI elements to ensure a modern look and consistent layout structure.
* **Framer Motion Micro-interactions:** Smooth page transitions, aesthetic hover states, stagger animations for responsive pet grids, and fluid layout shifts that significantly elevate UX.
* **Context-Aware Action Modals:** Beautiful interactive dark-themed request containers with built-in loading spinners, processing states, and conditional feedback responses.
* **Fluid Architecture & Error Boundaries:** Tailored design layouts optimizing interface views from mobile smartphone screens to wide desktop monitors, featuring custom bounce-animated error boundaries (`🐶💤`).
